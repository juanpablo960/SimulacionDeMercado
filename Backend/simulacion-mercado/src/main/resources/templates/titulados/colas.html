Análisis y Recomendación

Análisis de escenarios:

  • Escenarios simulados: 1, 2, 3, 4, 5 y 6 servidores.
  • Criterio: se busca una utilización entre 60% y 90% (óptimo).
  • Si la utilización es mayor al 90%, el servidor está saturado.
  • Si la utilización es menor al 60%, el servidor está subutilizado.

✅ Recomendación óptima: 2 servidores

Este es el menor número de servidores con utilización en el rango óptimo (60-90%).

📐 Fundamento Matemático

Carga de trabajo total:

λ × E[S] = 10 llegadas/hora × 10 min promedio = 3.33 unidades de trabajo por minuto

Fórmula de utilización:

ρ = (λ × E[S]) / c

Interpretación:

  • Si ρ > 1: el sistema se satura, la cola crece indefinidamente.
  • Si ρ > 0.9: el sistema está saturado, tiempos de espera altos.
  • Si 0.6 ≤ ρ ≤ 0.9: utilización óptima, tiempo de espera aceptable.
  • Si ρ < 0.6: subutilización, recursos desperdiciados.
